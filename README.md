## Portfolio Reflection

### Client and Software Requirements

Artemis Financial is a financial services company that wanted to improve the security of its web application. The goal of this project was to identify software security vulnerabilities and implement solutions that protected sensitive financial information while maintaining the application's functionality.

Working through this project gave me practical experience applying secure coding concepts to a real application rather than simply learning about them in theory.

### Software Security

One of the things I did well during this project was identifying security concerns and implementing improvements that strengthened the application's overall security. Instead of only learning about software security concepts, I was able to apply them through secure coding, encryption, certificate generation, and vulnerability testing.

Coding securely is important because it helps protect sensitive information, reduces the risk of cyberattacks, and builds trust between organizations and their customers. For financial organizations especially, strong software security helps reduce financial, legal, and reputational risks.

### Vulnerability Assessment

The most valuable part of the vulnerability assessment was learning how security tools can identify weaknesses that are not always obvious during development. Using OWASP Dependency-Check helped me better understand how vulnerable third-party libraries can impact an application's overall security and reinforced the importance of reviewing project dependencies throughout the software development process.

### Security Improvements

I strengthened the application's security by implementing HTTPS, generating a self-signed SSL certificate, configuring secure communications, and implementing SHA-256 checksum verification to validate data integrity.

In future projects, I would continue using automated vulnerability scanners, static analysis tools, dependency analysis, and secure coding best practices to identify security risks and determine appropriate mitigation strategies.

### Functional and Security Testing

After completing the refactoring, I verified that the application continued to function correctly by building and running the project successfully. I also performed additional testing using OWASP Dependency-Check to help ensure that the security improvements did not introduce new vulnerabilities while confirming that the application remained functional.

### Resources and Tools

Several tools contributed to the success of this project, including Eclipse, Maven, Java Keytool, Spring Boot, Java's security libraries, and OWASP Dependency-Check.

Learning how these tools work together provided valuable hands-on experience that I can apply to future software development and cybersecurity projects.

### Portfolio Value

This project demonstrates my ability to evaluate software security, identify vulnerabilities, implement secure coding practices, and verify that security improvements maintain application functionality.

It also highlights my experience with HTTPS, SSL certificates, SHA-256 hashing, vulnerability assessment, and secure software testing, making it one of the strongest examples of my software security skills and growth as a software developer.
